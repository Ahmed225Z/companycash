## P8 — التصدير والاستيراد (`1500460000000270`)

### P8.4 — الاستيراد بالمعاينة ومطابقة الأعمدة · high
**الهدف:** استيراد آمن من غير ما يخرب الداتا.

**المطلوب:**
- يقبل Excel / CSV / JSON.
- الخطوات: رفع → **مطابقة الأعمدة** → **معاينة dry-run** (أول 20 صف + عدد الأخطاء) → تأكيد → استيراد داخل Transaction.
- إنشاء البنود الناقصة تلقائياً (بخيار قابل للإيقاف).
- دعم كتابة البند الفرعي بالشكل `السلف > أحمد أشرف`.
- تقرير النتيجة: نجح X / فشل Y + ملف أخطاء قابل للتنزيل (رقم الصف + السبب).
- قالب فارغ قابل للتنزيل.
- كل عملية تتسجّل في `import_batches`.

**معيار القبول ✅** أي خطأ في أي صف → rollback كامل لو المستخدم اختار «الكل أو لا شيء».
**الاختبار 🧪** استيراد ملف فيه 3 صفوف غلط → المعاينة بتبيّنهم قبل أي كتابة.

### P8.5 — اختبار Round-trip (تصدير ← استيراد) · high
**الهدف:** ضمان سلامة الداتا.
**المطلوب:** اختبار آلي: تصدير كل الداتا → `migrate:fresh` → استيراد → مقارنة.
**معيار القبول ✅** عدد البنود والمصروفات والإجماليات متطابقة 100%، وشجرة البنود محفوظة بنفس الشكل.
**الاختبار 🧪** `php artisan test --filter=RoundTrip` بينجح.

**الاختبار 🧪** تنقّل بين الصفحات وملاحظة النعومة على جهاز متوسط.

### P9.4 — تفاعلات الجداول والمودالات والأزرار · normal
**المطلوب:** صفوف الجدول stagger 25ms + `auto-animate` عند الفرز/الفلترة · modal/drawer: scale .96→1 + backdrop blur بـ 260ms · أزرار: hover رفع 2px + توهج · press scale .97 · تبويبات بمؤشر منزلق · skeletons أثناء تحميل Livewire · نبضة واحدة عند أول ظهور للتحذير.

**الاختبار 🧪** فرز وفلترة الجدول مرات كتير متتالية.

### P9.5 — الأداء واحترام prefers-reduced-motion · high
**المطلوب:** كل الحركات على `transform` و `opacity` فقط · `will-change` عند الحاجة فقط · `prefers-reduced-motion: reduce` بيلغي كل الحركات.
